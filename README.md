# PNEUMA–EDGE UNIQUE v1.0

Исследовательская когнитивная архитектура, очищенная до четырех центральных слоев:

- **PNEUMA** — смысл, внутренняя согласованность, идентичность и нарративная непрерывность.
- **PHILOSOPHY** — ценности, рефлексия и принцип «золотой середины».
- **EDGE** — обучение, генерация гипотез, адаптация и безопасная интеграция изменений.
- **UNIQUE** — сохранение генеалогии изменений, воспроизводимость экспериментов и единый контур симбиоза.

Проект не утверждает, что PNEUMA является физической душой или что система обладает сознанием. Метафизические и религиозно-философские идеи используются как символические/эвристические источники проектирования.

## Возможности

- когнитивный цикл;
- долговременная JSON-память;
- граф знаний;
- простая модель мира;
- механизм самоанализа;
- планировщик;
- система ценностей;
- генератор гипотез;
- модуль самообучения;
- пять тестов стабильности;
- REST API;
- опциональная GPU-поддержка через PyTorch;
- Docker;
- Kubernetes;
- GitHub Actions CI;
- история изменений и экспорт состояния.

## Запуск

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
# .venv\Scripts\activate

pip install -r requirements.txt
uvicorn app.api:app --reload
```

API: `http://127.0.0.1:8000`
Документация FastAPI: `/docs`

CLI:

```bash
python -m app.main
```

Тесты:

```bash
pytest -q
```

Docker:

```bash
docker build -t pnevma-edge-unique .
docker run --rm -p 8000:8000 pnevma-edge-unique
```

## Архитектурный цикл

`observe → remember → model → reflect → plan → hypothesize → verify → learn → integrate`

Интеграция новой идеи происходит только после проверки совместимости. Неуспешная гипотеза не заменяет стабильное состояние.

## Пять тестов

1. PNEUMA coherence
2. Value consistency
3. Memory integrity
4. World-model consistency
5. Evolution/symbiosis stability

Случайный `random()` в качестве теста стабильности намеренно не используется.

## Ограничения

Проект является исследовательским прототипом. Он не реализует перенос человеческого сознания, «воскрешение» человека, доказательство существования души или физическое информационное поле Вселенной.
